  target: "#conditionBuilderHost"

data_array Neutral Output

Condition array format

Outer array means AND. Nested array means OR. A plain object is a single rule.

Meaning

Country starts with Ind
AND

( Account Status equals Active

OR

Customer Name contains Alex )

[
  {
    field: "country",
    type: "starts",
    value: "Ind"
  },
  [
    {
      field: "accountStatus",
      type: "=",
      value: "Active"
    },
    {
      field: "customerName",
      type: "like",
      value: "Alex"
    }
  ]
]
